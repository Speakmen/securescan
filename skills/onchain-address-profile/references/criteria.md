# 风险线索判定规则

本技能只输出"线索"，不输出"结论"。所有规则仅使用可从公开节点验证的数据，不引入任何外部黑名单或评分服务。

## 规则表 v0.1

| 编号 | 规则 | 触发条件 | 措辞 |
|---|---|---|---|
| R1 | 对手方高度集中 | 观察窗口内单一对手方交互笔数占比 ≥ 50% | "对手方高度集中……值得注意" |
| R2 | 空投猎手特征 | EOA 且流入笔数 ≥ 10 且流出 ≤ 流入 × 10% | "……建议进一步核实" |
| R3 | 合约持有大额原生币 | 合约账户原生币余额 > 1000 TRX | "常见于收款类合约，请确认来源" |
| R4 | 大流量地址 | 稳定币（USDT/USDC 等）累计流水量 > 100 万 | "属大流量地址" |
| R7 | 假充值攻击特征 | 单笔 value 位数 > 24（接近 uint256 上限）的转账 | "伪造事件日志，切勿据此确认充值到账" |

R7 说明：链上存在伪造 Transfer event 的假充值攻击（金额显示为 2^256-1 级别的天文数字）。此类交易不计入流量与对手方聚合，单独作为风险线索输出。这是收 USDT/USDC 的商户与交易所最常见的骗局之一。

## 明确不做的事

- 不查询、不引用任何黑名单数据库或第三方风控评分
- 不猜测合约协议名称（无浏览器 API 时无法可靠识别）
- 不给出"该地址安全/不安全"的二元结论
- 不构成投资或合规建议

## 观察窗口说明

TRC20 转账最多翻页 3 次 × 200 笔 = 600 笔。大流量地址的画像受窗口截断影响，报告需注明"最多观察 600 笔"。

## 扩展位（留待后续版本）

- R5 资金快速过手（进出时间差短、留存率低）
- R6 已知风险模式特征匹配（需要权威数据源后接入）
- EVM 链对手方分析（待官方历史索引 API 可用）
