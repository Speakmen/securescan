# 链上地址安全画像

把输入的链上地址转化为一份可读的安全画像报告：账户类型、余额与代币持仓、对手方集中度、活跃时间跨度、风险线索。数据全部来自公开节点（TronGrid / PublicNode），不需要用户提供任何 API Key。

## 使用流程

1. 识别链类型：
   - 地址以 `T` 开头且长度 34 → TRON
   - 地址以 `0x` 开头且长度 42 → EVM（以太坊主网）
   - 无法识别时向用户确认，不要猜测
2. 运行脚本生成画像：

```bash
python scripts/address_profile.py <地址>
```

可选参数：
- `--tx-limit N`：每类转账最多拉取笔数（默认 200，越大画像越全但越慢）
- `--json`：同时输出原始 JSON 摘要

3. 脚本输出 Markdown 报告。将报告直接呈现给用户，并在结尾附上数据来源说明（TronGrid / PublicNode 公共节点，数据有延迟）。

## 输出报告结构

- 账户类型：EOA 或智能合约（合约标注代码体积，不虚构协议名称）
- 原生币余额与交易计数
- TRC20 代币持仓 Top10（按转账流水量）
- 对手方 Top10：方向（转入/转出）、笔数、金额、代币
- 活跃度：首次/最近活动时间、观察窗口内交易笔数
- 风险线索：仅基于可验证数据的规则判断（见 references/criteria.md），不输出投机性结论

## 能力边界（必须向用户如实说明）

- TRON：全画像（类型/余额/代币/对手方/活跃度）
- EVM：点值画像（类型/余额/nonce）。以太坊公共节点不提供账户历史交易查询，对手方分析仅支持 TRON
- 合约的具体协议（如某 DEX 路由、某钱包工厂）在无浏览器 API 时无法可靠识别，报告只标注"智能合约+代码特征"，不得编造协议名
- 画像基于公开数据，不构成投资或合规建议；涉及资金安全决策请用户自行核实

## 判定规则

风险线索只使用以下规则（详见 references/criteria.md）：
- R1 对手方高度集中：单一对手方占观察窗口交互量 50% 以上
- R2 空投猎手特征：大量多来源转入、极少转出
- R3 合约持有大额原生币：常见于收款类合约
- R4 大流量地址：稳定币累计流水量超 100 万
- R7 假充值攻击特征：金额接近 uint256 上限的伪造转账（不计入统计，单独警示）

规则命中时输出"线索"而非"结论"，措辞使用"值得注意""建议进一步核实"。
